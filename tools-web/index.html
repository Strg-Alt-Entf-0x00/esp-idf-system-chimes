Hardware Quick Reference

Connect Hardware

Use the USB icon in the header to connect to the ESP32 over Web Serial at 115200 baud. Hardware controls unlock once the System Chimes firmware signature is verified.

Piano Roll Navigation & Mouse Wheel Controls

Click on the grid to create notes. Double-click, right-click, or press Del to delete the selected note. Hovering over any note displays its Pitch, Frequency, Start, and Duration in a floating tooltip.

  • Mouse Wheel: Scroll vertically through octaves and pitches
  • Shift + Wheel: Pan horizontally along the timeline
  • Ctrl + Wheel: Zoom in / out with HUD percentage feedback
  • Alt + Wheel: Cycle snap grid resolution (10ms, 25ms, 50ms, 100ms, 250ms, Off)

Playback Target

Toggle between PC Preview and ESP32 Speaker. In ESP32 mode, sound outputs through the physical speaker on the device.

Serial Console

Open the console with the terminal button to monitor commands or communicate directly with the ESP32 firmware.
